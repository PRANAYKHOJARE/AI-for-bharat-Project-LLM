# AI for Bharat – LLM Agent Workshop Project 🤖🇮🇳

This repository contains hands-on implementations and demos created as part of the **“AI for Bharat – Building Intelligent AI Agents with Amazon Bedrock and Strands”** workshop.

The project focuses on building **LLM-powered intelligent agents**, experimenting with **agentic workflows**, and deploying AI-driven solutions using **Amazon Bedrock**, **Strands**, and modern AI tooling.

## 🚀 Project Highlights

- 🤖 LLM-based intelligent agent creation  
- 🔐 AI-powered Network Intrusion Detection concepts  
- ☁️ Integration with Amazon Bedrock  
- 🧠 Agentic RAG (Retrieval-Augmented Generation) patterns  
- 📊 Real-world AI demos and experiments  
- 🛠 Python, Jupyter Notebooks, and cloud-native workflows

## 🧪 Workshop Objectives

- Understand agent-based AI architectures
- Build and deploy LLM agents
- Explore tool usage, memory, and orchestration
- Apply AI solutions to real-world Bharat-scale problems
